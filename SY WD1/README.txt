CAFFIN HUB — 3 PAGE WEBSITE

Files in this folder:
- index.html  : Home page
- menu.html   : Menu page
- about.html  : About + contact page
- style.css   : Custom styling for all pages
- cafe.svg    : Local image used in the website

HOW TO PREVIEW
1. Extract this ZIP file.
2. Keep all five files together in the same folder.
3. Open index.html in a browser. Internet is needed to load Bootstrap CSS/JS and Google Fonts from their CDNs.
4. Click Home / Our Menu / About Us to test the three pages.

BOOTSTRAP
This project uses Bootstrap 5.3.3 CSS and JavaScript through CDN links. Custom styling is in style.css.

NOTES
- Menu prices and cafe contact details are sample content for a student project.
- The contact button opens the user's email app; it is not a backend contact form.
- Replace sample contact information before using this as a real business website.
